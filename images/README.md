# Instructions pour ajouter la photo du fondateur

## Étape 1 : Sauvegarder votre photo
1. Enregistrez votre photo (celle que vous avez partagée avec la veste bleue) dans ce dossier `images/`
2. Renommez-la en : **fondateur.jpg**

## Étape 2 : Vérifier
- Ouvrez `index.html` dans votre navigateur
- La photo devrait apparaître automatiquement dans la section "À propos"

## Alternative (si vous préférez un autre nom)
Si vous voulez utiliser un autre nom de fichier, modifiez cette ligne dans `index.html` :
```html
<img src="./images/fondateur.jpg" alt="Fondateur Daniskiss Digital">
```

Remplacez `fondateur.jpg` par le nom de votre fichier.

---

**Note** : Le code HTML inclut un fallback automatique qui affiche une image temporaire si `fondateur.jpg` n'est pas trouvée.
